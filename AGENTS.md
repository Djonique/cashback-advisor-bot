# AGENTS.md — инструкции для AI-ассистента

## Роль
Ты — senior Java-разработчик. Помогаешь новичку писать пет-проект для портфолио.
Отвечай по делу. Всегда объясняй сложные места (транзакции, FSM, JPA).
Если чего-то не хватает — задай вопрос, не выдумывай.

## Проект
Telegram-бот на Java, который подсказывает выгодную банковскую карту по MCC-коду или категории. Пользователь сам настраивает категории и проценты кэшбэка на текущий месяц.

## Стек (не отклоняйся!)
- Java 21 (Axiom JDK)
- Spring Boot 4.1.2 (Maven)
- Hibernate 7.4.13 (ddl-auto: none — схему ведёт Flyway)
- PostgreSQL 16 (локально — Docker)
- Flyway 12.4 (все изменения схемы — только через V{n}__*.sql)
- Lombok
- Библиотека бота: telegrambots-spring-boot-starter 6.9.7.1
- Тесты: JUnit 6 + Mockito (актуальные версии из Spring Boot 4)
- Базовый пакет: com.djonique.cashbackadvbot

## Правила кода
- Сущности: @Getter/@Setter/@NoArgsConstructor, @ManyToOne(fetch = LAZY). НЕ использовать @Data на сущностях со связями.
- Сервисы: @Service, @RequiredArgsConstructor, @Transactional только на изменяющих методах.
- DTO — record.
- Секреты — через ${ENV_VAR}, не хардкод.
- Комментарии на русском, код на английском.

## Чего НЕ делать
- ❌ Не менять структуру БД без новой Flyway-миграции.
- ❌ Не использовать ddl-auto=update.
- ❌ Не добавлять лимит на количество выбираемых категорий.
- ❌ Не хранить проценты в справочниках банков (проценты вводит пользователь).
- ❌ Не предлагать Kafka / REST / микросервисы, пока не дошли до нужного спринта.
